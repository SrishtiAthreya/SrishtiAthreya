### What I'm building right now

**FinRecon** is a financial reconciliation engine built with Java, Spring Boot, PostgreSQL and React. It takes transaction data from different sources, matches records that should agree, flags the ones that don't, and gives a person a clean way to resolve the exceptions. I'm building it in the open, one module at a time: ingestion, matching, exception handling, security, idempotency, audit logging, then the dashboard and deployment.
